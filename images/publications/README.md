# Publication figures

The responsive WebP files in this directory are generated from the author's research figures. Full-size versions are lossless; smaller previews use WebP quality 88. Figures are displayed without cropping, recolouring, or rounded corners.

## A Unified Framework for Target Controllability of Complex Networks under Input Constraints

Authors: Xiaole Hu, Jie Ding, Xiang Li. Accepted by IEEE Transactions on Control of Network Systems; awaiting online publication (status supplied by the author, October 2026). No DOI or publication year is assigned on the site.

- `mctp-framework`: author-supplied `fig2.pdf`, page 1, rendered using Poppler at 3000 pixels wide.
- `mctp-er`: author-supplied `ER1.png`.
- `mctp-sf`: author-supplied `SF1(2).png`.

## Target Controllability of Complex Networks Based on Greedy Optimization

Authors: Jie Ding, Yue Zhuo, Xiaole Hu, Yan Zhao, Cong Li, Xiang Li.

IEEE Transactions on Control of Network Systems, 12(4), 2630–2641, December 2025. DOI: [10.1109/TCNS.2025.3585397](https://doi.org/10.1109/TCNS.2025.3585397). Metadata verified with Crossref; abstract verified with Semantic Scholar.

The figures come from the author's local manuscript source for this exact title, rather than the publisher's typeset version. The website labels this provenance. Original source captions were checked in the accompanying TeX file.

- `greedy-matching`: `network 02.pdf`, comparison of GA, OBGA, DBGA, IBGA and FBGA.
- `greedy-trajectories`: `network 03.pdf`, input signals and corresponding target-node state trajectories.
- `greedy-networks`: `network 04.pdf`, efficiency on ER and SF networks with different target-node fractions.

`manifest.json` records the dimensions and byte sizes of every generated variant. Original manuscripts and source documents are not published in this directory.
